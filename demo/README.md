# Traces du mode démo

- `sortie-40.gpx`, `sortie-70.gpx`, `sortie-150.gpx` (page Sortie ; 70 km ouverte par défaut)

- `velotaf-10.gpx` (page Vélotaf)

Copiées dans l'app par `app/scripts/build-www.mjs`.
